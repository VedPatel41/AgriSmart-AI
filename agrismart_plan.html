Team: 6 log (5 core + 1 support) Window: 10–15 September Core task: Crop Disease Detection (CV)

Approach in short

Problem statement ke hisaab se ek hi core task compulsory hai — leaf image se disease classify karna, macro-F1 aur confusion matrix report karna. Baaki sab (irrigation, weather, sustainability score, GenAI assistant, IoT, agentic layer) bonus hai. Poora build AI-assisted hoga: planning aur prompts ek AI se, actual code generation dusre AI se, aur review/testing phir se pehle wale AI se — is tarah se galtiyan kam hongi aur speed zyada milegi.

Bonus module — realistic combo

Sab 7 bonus modules try karna zaroori nahi, aur karna bhi mushkil hai time me. Ye 3 combo purely software/API se ban jaate hain, hardware ki zaroorat nahi:

  • Weather-Based Intelligence (C) — OpenWeatherMap se live data, simple rule-based actions ("delay irrigation - rain likely").
  • Smart Irrigation (B) — soil moisture ka simulated/manual input le lo, weather ke saath combine karke irrigation-needed/not-needed decide karo.
  • Farmer Assistant — GenAI (E) — Google Gemini API se disease result ko plain Hindi/Gujarati me explain karna.

Work Tracks

6 functional tracks hain, poore team ki count ke hisaab se. Track kisko milega ye team apne comfort ke hisaab se decide kare — ye sirf kaam ka scope define karta hai.

Track 1 — Core CV Model

Dataset preprocessing, transfer-learning model training, evaluation (macro-F1, confusion matrix). Ye sabse critical hai kyuki core task isi pe judge hota hai.

Track 2 — Backend & predict interface

Flask/FastAPI setup, predict() route, model loading, API structure jo Section 4.1 ke contract ko match kare.

Track 3 — Frontend / Web UI

Upload-image flow, result display, precaution text — simple aur farmer-friendly, mobile pe bhi kaam kare.

Track 4 — Bonus Modules

Weather intelligence + smart irrigation logic, sustainability score formula, API integrations.

Track 5 — GenAI Assistant & language

Google Gemini API se conversational explanation, regional-language output, prompt grounding.

Track 6 — Docs, Testing & Demo

README, model report, originality declaration, Postman testing, deployment, aur demo video editing. Ye track baaki 5 tracks ke saath overlap karke chalta hai, isliye support-role ke saath bhi accha fit hai.

Submission checklist

Judge sirf isi cheez ko dekhega — ye missing hui to AI/ML axis full nahi milega, chahe model kitna accha bhi ho.

  • /README.md — kaunse core+bonus modules bane, setup/run instructions (10 min me judge reproduce kar paaye), dataset source/licence, saare metrics, architecture overview, limitations, demo video link.
  • /src ya /app — source code.
  • /model — training + predict interface, weights (large ho to release/link se).
  • /report — one-page model report: task, dataset & split, model/approach, metric & result, baseline comparison, limitations.
  • requirements.txt + environment file + clear run instructions.
  • Originality declaration — README me third-party code/notebooks list karo jo reference liye.
  • Demo video — 3-5 minute, core task naye image pe chalta hua dikhna chahiye, plus bonus modules.
